# Archive

Runs from before Hermes became the ontology-based pipeline (October 2026), kept for audit: the baseline systems (training-free, UniQGen, the algebra agent, the prover, the budgeted planner) on CK26 and DB26, with their reports and leaderboard. `hermes report --results results/archive/2026-10-baselines` rebuilds that leaderboard.

New runs go to `results/<benchmark>/`.
